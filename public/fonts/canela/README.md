# Canela Font Directory

Place licensed Canela font files here for the Triads Future homepage hero heading.

### Supported File Formats:
- `Canela-Regular.woff2` (Weight: 400, Normal)
- `Canela-Regular.woff`
- `Canela-Medium.woff2` (Weight: 500, Normal)
- `Canela-Medium.woff`

The `@font-face` definitions are configured in `src/app/globals.css` with fallback to `Newsreader` and `Georgia, serif`.
